# ねずみ幸福論 — 音源配信記念サイト

Next.js / TypeScript の静的サイト。リリース日・更新履歴・書き込みは仮データです。

```sh
npm install
npm run dev
```

http://localhost:3000 で確認できます。

## コンテンツの変更

`content/site.ts` に編集用データを集約しています。

- `site.band / release / releaseDate`：バンド名、音源名、日付
- `site.intro / ticker`：トップの文章と流れるテキスト
- `site.homepage`：サイト名、固定カウンター、更新履歴、日記、読み取り専用の書き込み
- `popups`：勧誘ウィンドウの見出し、文章、ボタン、記号、色。追加・削除可能（1件以上必要）
- `site.animation`：増殖の時間、崩壊の時間、最大表示数
- `site.platforms`：配信先のURL。空欄のサービスは準備中表示
- `site.embed.url`：Spotify等の埋め込みコードに含まれる `src` URL。通常の共有URLとは異なります。`title / height` も設定可能

正式音源が未提供のため、他アーティストの音源は埋め込まずプレイヤーの仮表示にしています。`embed.url` を設定すると実際のiframeに切り替わります。音声は自動再生しません。最後は白いページの中央に音源とリンクだけを表示します。

## 演出

平成初期の個人サイトをイメージし、左メニュー・細い罫線・更新履歴で構成しています。メイン内容はブラウザ風の外枠を持たず、画面幅に合わせて広がります。受信ポップアップは別窓風の表示です。カウンターは演出用で、訪問者計測や掲示板への投稿機能はありません。

入信ボタン・勧誘ウィンドウのボタン → 約8.5秒で42枚まで増殖 → 約1.6秒の砂嵐・受信ノイズ → 白い音源ページ。窓は落下せず、その場でノイズに覆われて消えます。ノイズ素材は `public/images/noise.svg`、切替時間は `site.animation.collapseMs` で調整できます。演出中もスキップ可能。最後のページから再体験できます。OSの視差効果軽減を設定している場合は増殖を省略します。JavaScript無効時には配信情報と設定済みリンクを表示します。

## ビルド・公開

```sh
npm run typecheck
npm run build
```

生成された `out/` フォルダを静的ホスティングに配置します。Node.jsサーバーは不要です。設定は Next.js 公式の [Static Exports](https://nextjs.org/docs/app/guides/static-exports) に準拠しています。ドメイン直下での公開を想定しています。

デザインは古い通信端末をイメージした暗色テーマです。`app/transmission.css` で配色・走査線・警告ウィンドウを調整でき、`public/images/transmission.svg` が背景の電線です。フォントは端末の明朝体・等幅フォントを使い、外部フォントへの通信はありません。`site.transmission` で背景の通信ログを編集できます。ポップアップの `color` はデータ互換性のため保持していますが、現在はすべて赤系のエラー警告色に統一しています。表示・増殖・崩壊の全段階で窓を回転させません。

## ブラウザ検証

Google Chrome と Python 3 がある環境で `npm run build` 後に `npx playwright test` を実行できます。静的出力をローカル配信し、演出完走・スキップ・再体験・モバイル幅・動きの軽減設定を検証します。
